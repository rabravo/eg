## File

    Ctrl S                            ⌘ S                               # Save workbook

    Ctrl P                            ⌘ P                               # Print file
    Ctrl F2                           —                                 # Open print preview window
    Ctrl F4                           ⌘ W                               # Close current workbook
    Alt F4                            ⌘ Q                               # Close Excel
