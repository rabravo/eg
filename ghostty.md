# ghostty -- GPU-accelerated terminal emulator

## Launch normally

    ghostty

## Launch with a custom config file

    open -n -a Ghostty --args --config-file=$HOME/.config/ghostty/config-herdr

## Launch Herdr session (vanilla config)

    open -n -a Ghostty --args --config-file=$HOME/.config/ghostty/config-herdr

## Config file locations

    # Main config
    ~/Library/Application Support/com.mitchellh.ghostty/config

    # Custom configs
    ~/.config/ghostty/config-herdr

## Open config in editor (from inside Ghostty)

    ghostty +open-config

## Reload config without restarting

    # macOS: Cmd+Shift+,

## Create a new window

    # macOS: Cmd+N

## Create a new tab

    # macOS: Cmd+T

## Split pane horizontally

    # macOS: Cmd+D

## Split pane vertically

    # macOS: Cmd+Shift+D

## Navigate between splits

    # macOS: Cmd+Option+Arrow

## Increase / decrease font size

    # macOS: Cmd++ / Cmd+-

## Reset font size

    # macOS: Cmd+0
