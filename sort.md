# sort

sort lines alphabetically

    sort file.txt


sort in reverse order

    sort -r file.txt


sort numerically

    sort -n file.txt


sort by the second field (space-delimited)

    sort -k2 file.txt


sort a CSV by the third column numerically

    sort -t, -k3 -n file.csv


sort and remove duplicate lines

    sort -u file.txt
